# Brand assets

The Durable mark is for the repository, documentation, and project introductions. It shares Pulse's blue and waveform: an open D contour identifies Durable, the pulse represents continued execution, and the short baseline strokes represent stored checkpoints. It describes recovery, without promising that external side effects occur only once.

## Standard lockup

On a light background:

![Durable light-background wordmark](/brand/logo-light.svg)

Use `logo-dark.svg` on dark backgrounds. The README uses the blue-backed `logo.svg` so its contrast remains independent of the reader's theme.

## Choose an asset

| File | Purpose |
| --- | --- |
| `logo.svg` / `logo.png` | Blue-backed horizontal lockup for README and presentation |
| `logo-light.svg` | Transparent background and dark lettering for light pages |
| `logo-dark.svg` | Transparent background and light lettering for dark pages |
| `mark.svg` / `mark.png` | Standalone blue symbol |
| `mark-mono.svg` / `mark-inverse.svg` | Monochrome print and reversed artwork |
| `favicon.svg` / `favicon.png` | Small icon; checkpoint strokes omitted for legibility |

Master assets live in [`.github/assets`](https://github.com/Luo-root/pulse-durable/tree/main/.github/assets); the site uses copies in `site/public/brand/`. SVG lettering is outlined and requires no installed or remote font.

## Usage

Preserve aspect ratio and leave clear space of at least twice the symbol's stroke width. Use the full standalone mark at 32px or larger, and the simplified favicon at 16–24px. Prefer a lockup width of at least 180px; choose the symbol at smaller sizes.

The primary color is `#1E40AF`; the signal on dark backgrounds is `#60A5FA`. Recolor monochrome artwork as a whole. Do not move individual paths, add shadows, change stroke widths, or stretch the mark.

The outlined lettering is based on DejaVu Sans Bold. Its copyright notice accompanies the assets in `FONT-LICENSE.txt`. Project artwork follows the repository license.
